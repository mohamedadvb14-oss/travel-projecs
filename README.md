# رحلات العالم / World Trips (HTML + CSS) - النسخة المدموجة / Merged version
- العربي: `index.html` و`pages/` | English: `en/index.html` و`en/pages/` (نفس الهيكل). أي تعديل نص لازم يتعمل في النسختين.
- 33 مكان في 8 دول. أماكن مصر (9) صورها مختارة يدويًا من مشروع GoToEGYPT ومذكورة في صفحة `credits.html`.
- ميزات مدموجة: فلاتر الدول (radio + CSS) | lightbox لمعرض الصور (`:target`) | برنامج يوم بيوم | باقة عادية/فاخرة | شريط تقدم السكرول | مساعد أسئلة جاهز | صفحة نصائح السفر | صفحة حقوق الصور.
- `css/extras.css`: ملف الميزات المضافة. `css/base.css`: الألوان والخطوط. ترتيب الاستيراد: base, components, header, footer, extras, ملف الصفحة, responsive.
- `make_project.bat` (دبل كليك) بيعمل `project.html` ملف واحد للمشاركة. (الـ lightbox والفلاتر بتشتغل في النسخة المتعددة الملفات؛ في project.html الـ lightbox بيتعطل.)
- `refresh_images.py` بيستبدل صور الدول الأخرى بصور أدق (أماكن 5-28 فقط). راجع الصور بالعين بعدها.
- الصور خارج مصر بيانات المصور والترخيص فيها مش مدرجة واحدة واحدة؛ لازم تتراجع قبل التسليم.
